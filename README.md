# OpenMYO for Mac — downloads

OpenMYO is a free Mac app for making Yoto Make Your Own cards. Website: https://openmyo.com

**Download:** https://openmyo.com/download/mac (always the latest release below).

Requires a Mac with Apple silicon (M1 or newer) and macOS 12 or later. Install steps: https://openmyo.com/#get

This repository only hosts release files. OpenMYO is independent and is not made, endorsed or supported by Yoto.

## Open-source components

Each release includes the complete source code of the FFmpeg build bundled in the app (GNU GPL v3), plus the licence notices. See NOTICE.txt.
